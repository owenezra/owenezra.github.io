# Preserve the original Learning Voyage emblem

This signature edition deliberately references the existing original asset at:

`/docs/assets/images/LearningVoyageLogo.svg`

Deploy this package as an overlay onto the current `owenezra/owenezra.github.io` repository. Do not delete the existing `docs/` directory. The runtime includes a small compass fallback only so a missing asset does not break the layout; the intended production render is the original ship-and-night-sea emblem already in the repository.
